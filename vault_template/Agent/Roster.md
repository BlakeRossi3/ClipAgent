# Roster

The main assistant delegates to these sub-agents (defined in `agents/*.md` in the code repository):

- studio - the Shorts business
- ledger - hours, pay, income
- quartermaster - meals, routines, check-ins
- archivist - this vault
- researcher - questions that need looking up
- engineer - proposes improvements to its own skills (you approve them)
- briefer - morning brief, evening wrap, weekly review
